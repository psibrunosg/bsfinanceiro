# Issue tracker: GitHub

Issues and PRDs for this repository live as GitHub issues. Prefer the connected GitHub app for tracker operations; use the `gh` CLI when it is installed and authenticated.

## Conventions

- Create, read, list, label, assign, comment, and close through the connected GitHub app.
- When `gh` is available, use `gh issue create`, `gh issue view`, `gh issue list`, `gh issue comment`, `gh issue edit`, and `gh issue close`.

Infer the repository from the local `origin` remote.

## Pull requests as a triage surface

**PRs as a request surface: no.**

## Skill mappings

When a skill says to publish to the issue tracker, create a GitHub issue. When it asks for a relevant ticket, run `gh issue view <number> --comments`.
